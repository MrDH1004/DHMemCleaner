# DHMemCleaner 고도화 전략 리포트

> 작성일: 2026-05-21
> 대상: MemoryCleaner v1.0.0
> 작성자: Software Solution Review

---

## 1. 솔직한 현황 진단

메모리 클리너 카테고리는 **사양 시장**입니다.

- Windows 10/11이 메모리 관리를 잘하기 때문에 "더 빠르게, 더 자주 청소"는 차별화 안 됨
- 오히려 `EmptyWorkingSet`를 남발하면 페이지 폴트 유발로 성능이 떨어지는 사례 다수
- 경쟁자: CleanMem, Wise Memory Optimizer, Mz RAM Booster 등 — 모두 비슷한 기능

따라서 단순 클리너로 경쟁하면 승산 없음. **메모리 진단 + 인텔리전트 최적화 도구**로 포지셔닝 전환 필요.

---

## 2. 전략 방향 전환

| 구분 | AS-IS (v1.0) | TO-BE (v2.0) |
|------|--------------|--------------|
| 가치 제안 | "메모리를 청소합니다" | "메모리를 **이해**하고 **상황에 맞게** 최적화합니다" |
| 사용자 행동 | 느려질 때 버튼 클릭 | 앱이 알아서 판단, 사용자는 리포트 확인 |
| 차별점 | 청소 기능 (모두 있음) | **진단 + 컨텍스트 인식 + 학습** |
| 비즈니스 | 후원 (낮은 전환) | Pro 티어 (분석/리포트 기능) |

## 3. 3-Phase 로드맵

### Phase 1 — Trust 구축 (v1.5, 2~3주)

> 목표: "이 앱은 똑똑하구나" 인식 구축

#### ⭐ Killer Feature: 메모리 누수 감지기 (Memory Leak Detector)

- 프로세스별 워킹셋을 시계열로 추적 → 시간당 증가율이 일정 임계값을 넘는 프로세스를 자동 식별
- "Chrome.exe가 지난 30분간 +480MB 증가 — 누수 의심" 알림
- **유일한 차별점.** CleanMem, Wise 모두 못 함
- 기존 코드 재활용 가능: `MemoryHelper.GetTopProcesses` + 시계열 저장

#### 부가 기능

| 기능 | 설명 |
|------|------|
| 풀스크린/게임 모드 감지 | 자동정리 일시 정지. 필수. 안 하면 게이머 이탈 |
| 시계열 차트 | 정리 효과 시각화. `System.Windows.Forms.DataVisualization` 의존성 이미 추가됨 |
| EmptyWorkingSet 정책 개선 | 모든 프로세스 일괄 → "메모리 증가율 높은 상위 N개"만 타게팅 |

---

### Phase 2 — Differentiation (v2.0, 4~6주)

> 목표: 경쟁 앱과 명확한 격차

#### ⭐ Killer Feature: 상황 인식 자동 최적화 (Context-Aware Profiles)

3가지 모드 자동 전환:

| 모드 | 트리거 | 동작 |
|------|--------|------|
| 🎮 게임 모드 | 풀스크린 감지 | Chrome/Slack/OneDrive 워킹셋만 정리, 알림 무음 |
| 💼 작업 모드 | Excel/IDE 등 사무용 앱 활성 | 정리 빈도 낮춤, 해당 앱 제외 |
| 🌙 유휴 모드 | 마우스/키보드 5분 무입력 | 적극적 정리 + Standby 리스트 비우기 |

각 모드 사용자 정의 가능. 머신러닝 없이 **규칙 기반**으로 충분히 차별화됨.

#### 부가 기능

- **SQLite 영구 이력** + **주간 리포트** (이메일/팝업)
  - 예: "이번 주 12.4GB 절약, 평균 정리 후 RAM 18% 감소"
  - 후원/Pro 전환율 극대화 — 가치 증명이 시각적으로 보임
- **프로세스 화이트리스트** (정리 제외 목록)
- **글로벌 핫키** (`Ctrl+Alt+M` 즉시 정리)

---

### Phase 3 — Platform (v3.0, 8주+)

> 목표: 메모리 도구를 넘어 시스템 헬스 도구로

#### ⭐ Killer Feature: 시스템 헬스 스코어 + AI 어드바이저

- RAM/CPU/디스크/네트워크/온도/배터리 종합 100점 스코어
- "오늘 PC가 평소보다 느립니다 — 원인: dwm.exe 누수, Brave Browser 30개 탭"
- Claude API 또는 로컬 LLM(Llama 3.2 1B) 연동 → 자연어 진단 리포트
- **이게 진짜 차별점.** PC 모니터링 + 메모리 클리너를 합친 단일 SKU 없음

#### 부가 기능

- **CLI 모드**: `mc.exe --diagnose --json` (개발자/IT 어드민 타게팅)
- **Win11 효율 모드** 자동 적용: `PROCESS_POWER_THROTTLING_STATE`
- **다국어** (영어/일본어): 글로벌 확장

## 6. 즉시 시작 추천 (Phase 0)

**Phase 1의 두 기능만 먼저 만들기:**

1. **메모리 누수 감지기**
2. **풀스크린/게임 모드 감지**

### 이유

1. 기존 코드(`AutoCleanManager`, `MemoryHelper.GetTopProcesses`)를 재활용 가능 — **2주 안에 가능**
2. 한국/영어 IT 커뮤니티(클리앙, 뽐뿌, r/Windows10)에서 입소문 날 가능성이 가장 높은 기능
3. v1.0의 "또 하나의 메모리 클리너" 인식을 **단번에 깰 수 있음**

### 첫 2주 작업 계획

| 주차 | 작업 |
|------|------|
| Week 1 | 시계열 데이터 수집기 (`ProcessHistoryTracker`) 구현, 누수 판단 알고리즘 |
| Week 1 후반 | 풀스크린 감지 (`GetForegroundWindow` + `DwmGetWindowAttribute`) |
| Week 2 | UI 통합 — 대시보드에 "누수 의심 프로세스" 카드 추가 |
| Week 2 후반 | 알림 + 사용자 테스트 |

## 7. 핵심 차별화 요약

> **"메모리를 청소하는 도구가 아닌, 메모리 이상을 진단하는 도구"**

기존 메모리 클리너들이 답하지 못하는 질문에 답할 것:
- ❌ "메모리가 부족한가요?" → 작업 관리자도 답함
- ✅ **"왜 메모리가 부족한가요?"** → 우리만 답함
- ❌ "정리해주세요" → 모두 가능
- ✅ **"언제 정리할지 알아서 판단해주세요"** → 우리만 가능
- ❌ "얼마나 정리됐어요?" → 모두 표시
- ✅ **"정리가 정말 효과가 있었나요? 다시 차오르지 않나요?"** → 우리만 추적

| 시계열 데이터 저장 부담 | 디스크 사용량 | 24시간 롤링 + 일일 요약만 영구 보존 |
| Pro 티어 가치 검증 안 됨 | 비즈니스 모델 실패 | 베타에 Pro 기능 30일 무료 → 전환율 측정 후 가격 조정 |

## 9. 결론

**현재 v1.0은 기능적으로 완성도 높지만 카테고리 자체가 레드오션.**

차별화를 위한 단 한 가지 변화:
> "청소하는 도구"에서 → "진단하는 도구"로

이 전환은 **코드 베이스의 80%를 그대로 재활용**하면서 가능합니다. 신규 개발은 약 20%만 추가하면 됩니다.
