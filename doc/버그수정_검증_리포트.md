| 4 | AutoCleanManager.cs | 🟡 경미 | `_timeBasedTimer` 필드 선언만 하고 미사용 (CS0169 경고) | 미사용 필드 제거 |

| 6 | AutoCleanManager.cs | 🟠 기능 | `History` 타이머 스레드 Write + UI 스레드 Read 동시 접근 → `InvalidOperationException` 위험 | `_historyLock` 객체로 락 추가 |
| 7 | AutoCleanManager.cs | 🟠 기능 | 앱 시작 직후 `_lastTimedClean=MinValue`로 첫 틱에 즉시 자동 정리 발동 | `Start()`에서 `DateTime.Now`로 초기화 |

| 9 | DonateControl.cs | 🟠 기능 | `Process.Start("url")` — .NET 8에서 `UseShellExecute=true` 없으면 실패, 예외 묵음 처리 | `ProcessStartInfo { UseShellExecute = true }` 사용 |

| 11 | HistoryControl.cs | 🟡 경미 | `RefreshList()` BuildUI 내 + 생성자에서 2번 호출 | BuildUI 내 중복 제거 |

## 4. 잔존 이슈 (개선 권장)

| 이슈 | 심각도 | 설명 |
|------|--------|------|
| `💝` 이모지가 RoundButton에서 `□`로 렌더링됨 | 🟢 Cosmetic | RoundButton의 커스텀 GDI+ 폰트(Segoe UI)가 컬러 이모지 미지원. `Segoe UI Emoji` 폰트 폴백 필요 |
| Settings 콤보박스에 저장된 임계값이 옵션에 없으면 silent fallback | 🟡 경미 | 예: threshold=0 저장 시 UI에는 "40" 표시되지만 실제 값은 0. 사용자 정의 값 지원 또는 알림 필요 |
| ListView 컬럼 헤더가 다크테마와 어울리지 않음 | 🟢 Cosmetic | WinForms ListView의 OS 기본 헤더가 다크 배경과 대비 약함. OwnerDraw 또는 ObjectListView 라이브러리 검토 |
